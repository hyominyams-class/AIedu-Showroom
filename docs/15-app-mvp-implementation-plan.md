# 현재 앱 구성 기준

## 원칙

- 내부 체험 앱은 웹앱 기능, 로컬 저장, 파일 입력, 지도 API, 이미지 API, 텍스트 생성 API로 실제 MVP가 가능한 문제만 둔다.
- 웹앱이 직접 해결하지 못하는 하드웨어 의존, LMS 의존, 수학 문제풀이 흉내 앱은 목록에서 제외한다.
- `상` 난이도는 내부 체험 앱이 아니라 외부 완성형 링크 카드로만 둔다.
- `상` 카드는 `/apps/[slug]/work` 라우트를 만들지 않는다.
