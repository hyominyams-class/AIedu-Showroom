# 앱별 MVP 범위

## 내부 체험 앱

| 앱 | MVP 기능 |
| --- | --- |
| 수업 타이머 스테이션 | 시간 설정, 모둠 수, 발표 순서, 교실 보드 |
| 독서여권 스탬프북 | 책 기록, 스탬프, 누적 기록 |
| 카드뉴스 캠페인 메이커 | 카드 문구 편집, 캠페인 원고 저장 |
| 과학 실험 절차 카드 | 준비물, 관찰 기준, 관찰 메모 |
| 그림책 장면 제작기 | 이야기 입력, 이미지 생성 API, 장면 문장 |
| AI 질문 생성 도우미 | 주제 입력, 텍스트 생성 API, 질문 카드 |
| 발표 피드백 코치 | 대본 입력, 텍스트 생성 API, 피드백 카드 |
| AI 발명 설계소 | 스케치 업로드, 이미지 생성 API, 발명 포스터 |
| 생활 안전 웹툰 생성기 | 안전 주제 입력, 이미지/텍스트 생성 API, 4컷 결과 |
| 탐구 프로젝트 포트폴리오 | 칸반 카드, 새 카드 추가, 완료 상태 저장 |
| 지역 문제 데이터 맵 | 지도 마커, 위험도 조절, CSV 저장 |
| 학급 챗봇 허브 | 자료 텍스트, 학생 질문, AI 답변 카드 |

## 외부 링크 앱

| 앱 | MVP 처리 |
| --- | --- |
| 경제교육 웹 | 카드 클릭 시 외부 URL로 이동 |
| 질문수업(스마일 프로젝트) | 카드 클릭 시 외부 URL로 이동 |
| 미정 | 카드 클릭 시 외부 URL로 이동 |

## 제외 기준

- 단순 수학 문제풀이처럼 웹앱 기능보다 콘텐츠 흉내에 가까운 항목은 제외한다.
- 하드웨어 실측값 없이 대시보드만 흉내 내는 항목은 제외한다.
- LMS나 대규모 학습 로그 없이 리포트만 보여주는 항목은 제외한다.
