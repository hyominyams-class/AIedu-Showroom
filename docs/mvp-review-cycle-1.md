# MVP 리뷰 기록

## 현재 판단

- 내부 체험 앱은 12개다.
- `상` 난이도 앱은 3개이며 모두 외부 링크 카드다.
- 제거 대상 앱은 소스 목록과 내부 라우트 생성 대상에서 제외했다.

## 제거한 항목

| 항목 | 이유 |
| --- | --- |
| 퀴즈 카드 빌더 | 수학 문제풀이/문항 카드 흉내에 가까움 |
| 교실 IoT 대시보드 | 실제 하드웨어 데이터 없이 대시보드 흉내가 됨 |
| 학습 분석 리포트 메이커 | 실제 학습 로그 없이 리포트 흉내가 됨 |
