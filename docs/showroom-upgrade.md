## 구현 범위

외부 서비스의 구현은 제외하고, 공통 홈·목록과 내부 앱 16개를 개선했다. 기존 작업 트리의 카탈로그·썸네일 변경은 보존했다.

- 상단에 앱 이름, 현재 단계/탭, 이전·다음, AI 잔여 횟수를 표시한다.
- 제작 앱은 입력·표현·결과를 분리하고, 도구는 설정·실행·장부를 탭으로 이동한다.
- 개념 설명은 카드별, 학습지는 문항별, 앱 내부 장부는 페이지/제한된 영역으로 읽는다. 쇼룸 앱 목록은 페이지를 나누지 않고 전체 33개를 난이도 하 → 중 → 상 순으로 표시한다.
- 조작은 Pretendard와 공통 버튼·입력·간격으로 통일한다. 작품과 이야기의 서체는 용도를 따른다.
- 그림책·발명 이미지 2개는 실제 생성한다. 발명은 선택한 시안 한 장을 만들고 업로드를 반영한다.
- 이미지 안의 글자는 모델이 직접 생성한다. 별도 글자 합성·수정은 하지 않는다.
- 생성 실패를 준비된 결과로 숨기지 않는다. 대기·실패·제한 도달과 기존 결과 복구를 제공한다.
- 입력 초기화 뒤에도 저장한 AI 결과를 다시 열 수 있다. 대화 저장·이미지 다운로드·학습지 인쇄를 지원한다.
- 학급 장부는 조작 즉시 반영한다. 투표 예시는 자동으로 생기지 않고 명시적 버튼으로 추가한다.

## AI 사용량과 보관

| 앱 | 브라우저별 제한 |
| --- | --- |
| 작가 챗봇·개념 설명기·학습지 생성기 | 각 20회 |
| 그림책·발명 설계소 | 각 3회 |

서명된 HttpOnly 방문자/입장 쿠키와 비공개 Vercel Blob을 사용한다. 조건부 쓰기로 동시 생성을 잠그고, 성공 결과만 차감한다. 같은 요청은 저장 결과를 재사용한다. 새로고침·재접속·입력 초기화·재배포로 사용 횟수가 복구되지 않는다.

`OPENAI_API_KEY`, `SHOWROOM_SESSION_SECRET`, `BLOB_READ_WRITE_TOKEN`은 서버 환경변수다. 로컬 비밀 파일과 검사 산출물은 Git·Vercel 업로드·함수 추적에서 제외했다. 기본 모델은 `gpt-5-mini`, `gpt-image-2.5-flare`다. 업스테이지 연동은 추가하지 않았다.

## 운영 범위

- 익명 브라우저 기준이다. 쿠키 삭제나 다른 브라우저는 새 방문자로 취급된다.
- 학급 장부·투표는 해당 기기에서 체험하며 다중 사용자 동기화 서비스는 아니다.
- 화면을 억지로 잘라 맞추지 않는다. 작은 화면과 긴 내용에는 필요한 스크롤을 허용하고 상단 이동을 유지한다.
- 운영 검증은 CLI 프로덕션 배포에서 완료했다. 동일한 변경을 Git 저장소에도 반영해 후속 자동 배포에서 유지한다.
