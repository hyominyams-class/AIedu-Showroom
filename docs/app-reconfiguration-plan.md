# 앱 재구성 계획

## 기준

이 쇼룸의 앱은 구현 난이도를 `하`, `중`, `상`으로 나눈다. 난이도는 수업 아이디어의 가치가 아니라 실제 개발에 필요한 기술 범위를 기준으로 한다.

| 난이도 | 개발 기준 | 쇼룸에서 보여줄 방향 |
| --- | --- | --- |
| 하 | HTML, CSS, JavaScript, 정적 데이터만으로 구현 가능한 앱 | 입력, 선택, 카드, 타이머, 퀴즈처럼 즉시 만들 수 있는 수업 도구 |
| 중 | 단일 API 키를 활용하는 이미지 생성, 챗봇, 텍스트 생성 앱 | AI 응답, 이미지 결과, 피드백처럼 API 연결 후 확장되는 수업 도구 |
| 상 | 여러 API 키, 외부 서비스 연동, 인증, 저장소, 장기 프로젝트 구조가 필요한 앱 | 데이터 저장, 협업, IoT, 지도, 학습 분석처럼 프로젝트형으로 확장되는 도구 |

## 하: 기본 코드 기반 앱

| 앱 | 수업 장면 | 핵심 기능 |
| --- | --- | --- |
| 수업 타이머 스테이션 | 모둠 활동 시간 관리 | 타이머, 단계 안내, 발표 순서 |
| 퀴즈 카드 빌더 | 형성평가와 복습 | 문제 카드, 정답 확인, 난이도 표시 |
| 독서여권 스탬프북 | 독서 기록 | 나라/장르 선택, 생각 기록, 스탬프 |
| 카드뉴스 캠페인 메이커 | 사회 문제 캠페인 | 4장 카드뉴스 초안, 주장과 근거 정리 |
| 과학 실험 절차 카드 | 탐구 수업 | 준비물, 단계, 관찰 질문 |

## 중: 단일 API 키 활용 앱

| 앱 | API 유형 | 핵심 기능 |
| --- | --- | --- |
| 그림책 장면 제작기 | 이미지 생성 | 주제, 인물, 배경을 바탕으로 장면 이미지 제작 |
| AI 질문 생성 도우미 | 챗봇/텍스트 생성 | 글 주제에서 수준별 질문 생성 |
| 발표 피드백 코치 | 챗봇/텍스트 생성 | 발표 대본 피드백과 수정 문장 제안 |
| AI 발명 설계소 | 이미지 생성 | 아이디어 스케치를 설계도와 시제품 이미지로 확장 |
| 생활 안전 웹툰 생성기 | 이미지/텍스트 생성 | 안전 주제를 4컷 웹툰 흐름으로 변환 |

## 상: 외부 연동과 프로젝트형 앱

| 앱 | 연동 범위 | 핵심 기능 |
| --- | --- | --- |
| 마이크로비트 교실 IoT 대시보드 | 하드웨어, 클라우드 데이터 | 센서값 수집, 알림, 실시간 대시보드 |
| 탐구 프로젝트 포트폴리오 | 인증, DB, 파일 저장 | 팀별 산출물 저장, 피드백, 발표 자료 |
| 지역 문제 데이터 맵 | 지도 API, 공공데이터, 시트 | 지역 데이터를 지도와 카드로 시각화 |
| 학습 분석 리포트 메이커 | LMS, 스프레드시트, LLM | 학습 기록 분석, 개인별 리포트 |
| 학급 챗봇 허브 | RAG, 파일 저장, 다중 모델 | 학급 자료 기반 챗봇과 권한 관리 |

## 적용 원칙

1. 쇼룸 카드와 체험 페이지는 이 계획의 15개 앱을 기준으로 만든다.
2. 모든 체험 결과는 정적 목업 데이터이며, 사용자가 입력한 일부 문구만 결과에 반영한다.
3. 난이도 태그는 `하`, `중`, `상` 표기만 사용한다.
4. `하` 앱은 코드 기반 도구의 즉시성을, `중` 앱은 단일 API 연결 가능성을, `상` 앱은 연동 구조와 프로젝트 확장성을 보여준다.
5. 실제 API 키, 로그인, DB 저장은 이번 프로토타입에 넣지 않는다.
